## IDE / Editor Extensions

### Intelephense (PHP Language Server)
Licensed (Premium). Available in Claude Code via the `php-lsp@claude-plugins-official` plugin. License key at `~/intelephense/`.

**Free features:** Code completion, signature help, go to definition, find all references, symbol search, diagnostics, formatting, embedded languages, hover, highlight, advanced types.

**Premium features (licensed):** Rename, code folding, find all implementations, go to type definition, go to declaration, smart select, code actions, code lens, type hierarchy, inlay hints, document links.
